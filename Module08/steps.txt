8.5 Transfer Learning

| Step                    | What Happens                 |
| ----------------------- | ---------------------------- |
| Load images             | Resize, batch, one-hot label |
| Create Xception base    | Pretrained on ImageNet       |
| Freeze base_model       | Keep learned visual features |
| Add pooling + Dense(10) | Custom classifier            |
| Compile                 | Use crossentropy + Adam      |
| Train                   | Only classifier learns       |
| Evaluate                | Check validation accuracy    |
